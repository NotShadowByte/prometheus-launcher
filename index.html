Install in three steps

It takes about a minute. There is nothing to configure before you start.

  1. Download the file

    Press the download button. Save Prometheus_Launcher.exe anywhere you like.

  2. Run the app

    Double-click the file. If Windows shows a blue warning, choose More info, then Run anyway.

  3. Add an account and play

    Create or add an account, make an instance, and press Play.

Questions and help

Quick answers to the things people ask most.

Why does Windows show a warning when I open it?

Windows warns about apps from newer or independent publishers it has not seen before. Choose More info, then Run anyway to open Prometheus Launcher.

Google Drive says it can't scan the file for viruses

The launcher is a large file, and Drive shows this notice for any file that big. Choose Download anyway to continue.

Can I use more than one version or mod setup?

Yes. Make a separate instance for each one in the Instances section, and each keeps its own mods and settings.

Does it run on Mac or Linux?

Prometheus Launcher is a Windows app for now.
